# Projet Chat CVM

## Installation

1. Copier le fichier suivant sur votre poste de travail (sur le bureau) : V:\FTHERIAULT\00 - Logiciels de cours\IA\inférence-local.ps1
2. Exécutez le fichier avec PowerShell et choisir le plus petit modèle à charger. Laisser le programme roulé.
3. Ouvrez le laboratoire dans Visual Studio Code et chargez le fichier index.html dans le navigateur.

## Laboratoire

1. Compléter l'interface du fichier index.html
2. Compléter l'interface du fichier chat.html


## Notes
- Ne pas toucher au code existant, simplement ajouter votre code HTML et CSS dans les fichiers global.css et index.html.
- Quelques informations sont fournies dans le fichier CSS.
